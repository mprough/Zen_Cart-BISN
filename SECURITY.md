# Reporting security concerns

Report vulnerabilities privately through https://prowebsinc.zohodesk.com/portal/en/newticket.

Include the affected version, a concise reproduction, and redacted logs. Do not post customer information, credentials, live unsubscribe tokens, or a database dump in public.

The maintained scope is Back in stock notifications 4.x on Zen Cart 2.1.0 and 2.2.2. Unsupported legacy loose-file releases should be migrated.
